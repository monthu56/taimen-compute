API

Four calls to production memory

REST, OpenAPI-described, key-authenticated. Scope travels with the request; filtering happens server-side.

REQUEST 
curl https://api.taimen.ai/v1/memories \
  -H "Authorization: Bearer $TAIMEN_KEY" \
  -d scope="team:support" \
  -d text="Acme requires SAML SSO before rollout" \
  -d source="ticket/4821" \
  -d ttl="none"
 
curl -G https://api.taimen.ai/v1/search \
  -H "Authorization: Bearer $TAIMEN_KEY" \
  -d query="what did this customer ask about SSO?" \
  -d scopes="org:acme,team:support,user:u_812" \
  -d limit=5
 
curl https://api.taimen.ai/v1/forget \
  -H "Authorization: Bearer $TAIMEN_KEY" \
  -d scope="user:u_812" \
  -d reason="gdpr_erasure" \
  -d mode="soft"
 
curl https://api.taimen.ai/v1/share \
  -H "Authorization: Bearer $TAIMEN_KEY" \
  -d memory_id="mem_9f21c" \
  -d with="team:sales" \
  -d access="read"
